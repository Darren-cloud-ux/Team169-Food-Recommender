To generate the processed data:
1. Download the 'Branded' dataset from https://fdc.nal.usda.gov/download-datasets in .csv format
2. In your working directory, create a folder titled 'data'.
3. In the 'data' folder, create a folder titled "FoodData_Central_branded_food_csv_2025-04-24"
4. Unzip the downloaded data and save the raw datasets into the folder "FoodData_Central_branded_food_csv_2025-04-24"
5. Run "get nutrient summary.ipynb" from your working directory
6. Find "food_nutrition_summary_brand_names.csv" in the folder "data\FoodData_Central_branded_food_csv_2025-04-24"
